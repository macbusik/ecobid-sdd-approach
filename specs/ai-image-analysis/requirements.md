# Requirements Document: AI Image Analysis

## Introduction

The AI Image Analysis feature enables the "Snap & Sell" capability for EcoBid, allowing users to automatically generate item listings from uploaded photos. The system uses Amazon Rekognition for object detection and Amazon Bedrock (Claude 3 Haiku) for natural language generation to create compelling item metadata without manual data entry.

## Glossary

- **Image_Analyzer**: The AWS Lambda function that orchestrates AI processing of uploaded images
- **Rekognition_Service**: Amazon Rekognition API for object detection and label extraction
- **Bedrock_Service**: Amazon Bedrock API using Claude 3 Haiku model for text generation
- **Item_Record**: A DynamoDB record representing a marketplace item with AI-generated metadata
- **Storage_Bucket**: The S3 bucket where user-uploaded images are stored
- **AI_Tags**: Array of labels detected by Rekognition (e.g., "Chair", "Wooden", "Furniture")
- **AI_Description**: Natural language description generated by Bedrock
- **Condition_Assessment**: AI-generated evaluation of item condition (e.g., "Good", "Fair", "Excellent")
- **Draft_Status**: Initial item status before AI processing
- **Review_Status**: Item status after successful AI processing, ready for user review

## Requirements

### Requirement 1: Image Upload Trigger

**User Story:** As a user, I want the AI analysis to start automatically when I upload an image, so that I don't have to manually initiate processing.

#### Acceptance Criteria

1. WHEN a user uploads an image to the Storage_Bucket, THEN THE Image_Analyzer SHALL be triggered within 2 seconds
2. WHEN the Image_Analyzer is triggered, THEN THE Image_Analyzer SHALL receive the S3 object key and bucket name
3. IF the uploaded file is not an image format (JPEG, PNG, HEIC), THEN THE Image_Analyzer SHALL log an error and terminate processing
4. WHEN the Image_Analyzer starts processing, THEN THE Image_Analyzer SHALL retrieve the image from the Storage_Bucket

### Requirement 2: Object Detection

**User Story:** As a user, I want the system to identify objects in my photo, so that accurate tags and descriptions can be generated.

#### Acceptance Criteria

1. WHEN the Image_Analyzer receives an image, THEN THE Image_Analyzer SHALL call Rekognition_Service detectLabels API
2. WHEN calling Rekognition_Service, THEN THE Image_Analyzer SHALL request a minimum confidence threshold of 70%
3. WHEN Rekognition_Service returns labels, THEN THE Image_Analyzer SHALL extract label names and confidence scores
4. WHEN Rekognition_Service returns more than 10 labels, THEN THE Image_Analyzer SHALL select the top 10 labels by confidence score
5. IF Rekognition_Service fails or times out, THEN THE Image_Analyzer SHALL log the error and continue with empty labels array

### Requirement 3: Content Generation

**User Story:** As a user, I want the system to generate an appealing title and description for my item, so that potential buyers are attracted to my listing.

#### Acceptance Criteria

1. WHEN the Image_Analyzer has extracted labels, THEN THE Image_Analyzer SHALL construct a prompt for Bedrock_Service
2. WHEN constructing the prompt, THEN THE Image_Analyzer SHALL include all detected labels and request title, description, and condition assessment
3. WHEN calling Bedrock_Service, THEN THE Image_Analyzer SHALL use the Claude 3 Haiku model identifier
4. WHEN calling Bedrock_Service, THEN THE Image_Analyzer SHALL set max_tokens to 500 to control costs
5. WHEN Bedrock_Service returns a response, THEN THE Image_Analyzer SHALL parse the JSON response containing title, description, and condition fields
6. IF Bedrock_Service returns malformed JSON, THEN THE Image_Analyzer SHALL retry parsing with error recovery
7. IF Bedrock_Service fails after retry, THEN THE Image_Analyzer SHALL use fallback values based on detected labels

### Requirement 4: Database Update

**User Story:** As a user, I want my item record to be automatically updated with AI-generated content, so that I can review and publish my listing quickly.

#### Acceptance Criteria

1. WHEN the Image_Analyzer has generated content, THEN THE Image_Analyzer SHALL update the Item_Record in DynamoDB
2. WHEN updating the Item_Record, THEN THE Image_Analyzer SHALL set the aiTags field to the array of detected labels
3. WHEN updating the Item_Record, THEN THE Image_Analyzer SHALL set the aiDescription field to the generated description
4. WHEN updating the Item_Record, THEN THE Image_Analyzer SHALL set the aiConditionAssessment field to the generated condition
5. WHEN updating the Item_Record, THEN THE Image_Analyzer SHALL change the status field from Draft_Status to Review_Status
6. IF the DynamoDB update fails, THEN THE Image_Analyzer SHALL retry up to 3 times with exponential backoff
7. IF all retry attempts fail, THEN THE Image_Analyzer SHALL log the error and throw an exception

### Requirement 5: Performance and Cost Constraints

**User Story:** As a system operator, I want the AI analysis to stay within AWS Free Tier limits, so that the service remains cost-effective during prototyping.

#### Acceptance Criteria

1. WHEN processing an image, THEN THE Image_Analyzer SHALL complete within 5 seconds under normal conditions
2. WHEN calling Rekognition_Service, THEN THE Image_Analyzer SHALL process images that contribute to the 5,000 images per month Free Tier limit
3. WHEN calling Bedrock_Service, THEN THE Image_Analyzer SHALL use prompts under 200 tokens to minimize costs
4. WHEN calling Bedrock_Service, THEN THE Image_Analyzer SHALL set max_tokens to 500 to control response costs
5. THE Image_Analyzer SHALL log token usage for monitoring Free Tier consumption

### Requirement 6: IAM Permissions

**User Story:** As a system administrator, I want the Lambda function to have appropriate permissions, so that it can access required AWS services securely.

#### Acceptance Criteria

1. THE Image_Analyzer SHALL have IAM permission for rekognition:DetectLabels action
2. THE Image_Analyzer SHALL have IAM permission for bedrock:InvokeModel action
3. THE Image_Analyzer SHALL have IAM permission for s3:GetObject action on the Storage_Bucket
4. THE Image_Analyzer SHALL have IAM permission to read and write Item_Record in DynamoDB
5. THE Image_Analyzer SHALL NOT have permissions beyond those required for its function

### Requirement 7: Error Handling and Logging

**User Story:** As a developer, I want comprehensive error handling and logging, so that I can debug issues and monitor system health.

#### Acceptance Criteria

1. WHEN any AWS service call fails, THEN THE Image_Analyzer SHALL log the error with service name, operation, and error details
2. WHEN processing starts, THEN THE Image_Analyzer SHALL log the image key and timestamp
3. WHEN processing completes successfully, THEN THE Image_Analyzer SHALL log the generated metadata and processing duration
4. IF an unrecoverable error occurs, THEN THE Image_Analyzer SHALL log the full error stack and return a failure response
5. WHEN logging, THEN THE Image_Analyzer SHALL use structured JSON format for CloudWatch Logs parsing

### Requirement 8: Prompt Engineering

**User Story:** As a product owner, I want the AI-generated content to be accurate and appealing, so that users trust the system and listings attract buyers.

#### Acceptance Criteria

1. WHEN constructing the Bedrock prompt, THEN THE Image_Analyzer SHALL include instructions for generating concise, appealing titles
2. WHEN constructing the Bedrock prompt, THEN THE Image_Analyzer SHALL include instructions for generating detailed, honest descriptions
3. WHEN constructing the Bedrock prompt, THEN THE Image_Analyzer SHALL include instructions for assessing condition based on visual cues
4. WHEN constructing the Bedrock prompt, THEN THE Image_Analyzer SHALL request JSON-formatted output with specific field names
5. THE Image_Analyzer SHALL include example output format in the prompt to improve response consistency
